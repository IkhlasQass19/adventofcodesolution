# Advent of Code Solutions

This repository contains my solutions for problems from
[Advent of Code](https://adventofcode.com/).

The solutions are organized by year and day. Each day folder may include:

- The solution source code
- The puzzle/input data used while solving
- Any notes or text files related to the problem

## Repository Structure

```text
Year2025/
  Day 1: Secret Entrance/
  Day 2: Gift Shop/
  Day 3: Lobby/
```

## Running Solutions

Most solutions are written in Python. To run a solution, open the matching day
folder and execute the Python file, for example:

```bash
python3 "Year2025/Day 3: Lobby/Lobby.py"
```

## Note

Advent of Code puzzles and inputs belong to Advent of Code and their respective
creator. This repository is only for storing my personal solution attempts.
